# Simple Port Scanner

This is a simple Python port scanner that I built as part of my cybersecurity learning journey.

## What this project does
- Takes a target IP or domain
- Scans ports from 1 to 1024
- Identifies open ports

## What I learned
- Basics of networking and ports
- How TCP connections work
- Using Python socket library
- Basic error handling in Python

## How to run

```bash
python scanner.py
